## 凭据边界

完整占位值免疫仅适用于内置规则，不是跳过整个字段或整条记录。占位符后缀、同一正文的其他真实凭据、metadata 的非占位值仍拒绝；自定义 secretPatterns 继续执行。已脱敏记录切换模式后无需迁移。

对于有效 JSON，内置凭据扫描保留原有结构、未修改的转义、数字字面量和排版；不会把整篇 JSON 解析为浮点数再序列化。被修改的字符串按外层引号重新编码；敏感键对应容器或非字符串值时，整体替换成字符串占位符。

原始未引用凭据以空白、逗号、分号或结构闭合符为边界，内部引号属于值；以引号开头的值支持转义和空格，闭合引号后紧邻的值后缀一并隐藏。引号未闭合时保守处理剩余内容。规则仍不是通用 DLP，也不会修复任意输入格式；自定义正则若匹配 JSON 语法字符，不保证 JSON 可解析。
